# Photonic Architecture Explorer v0.3.0 (P0~P3)

Windows x64 오프라인 패키지입니다. 설치 없이 ZIP을 풀고 `Start-Photonic-Architecture-Explorer.cmd`를 실행하면 Chrome 또는 Edge에 화면이 열립니다(127.0.0.1, 인터넷 불필요).

## 할 수 있는 것
- 두 Port(Source·Target)를 입력하거나 3D에서 옮기고, 3D와 2D 도면(XY/XZ/YZ, Fold 전개)으로 배치를 확인
- 두 반사면 Relay 후보 자동 생성: Exact(η = 1) 또는 Guard 안 Near-match, 목표별 후보(최단 광경로, Guard 여유, 작은 Beam, 완만한 곡률, 정렬 공차, 비근축 Overlap 최대)
- 공간·제작 제약: Port 뒤 공간, 최대 입사각, 최소 곡률반경, Package Envelope, Keep-out
- Glass 매질: 수직 Fiber → Glass 상면 → Glass 안 반사면 → 매립 도파로, TIR 가능 여부 표시
- 평면 밖 경로(비동일평면 Port): 3D q-tensor 모델, 실제 곡면 광선으로 따로 검산
- 비근축 Scalar 검산: 모든 후보의 비근축 η, Guard 밖 Port(S3)는 연구 표만 표시
- 입력·결과 JSON, 도면 SVG 내보내기

## 알아둘 점
- η와 비근축 η는 Scalar Mode Overlap이며 Total Coupling, 조립 공차, Package, 특허성은 계산하지 않습니다.
- 반사면 처방은 국소 이차곡면입니다. 두 반사면이 같은 방향으로 꺾는 배치(예: S1, S4)는 Coma 때문에 비근축 η가 크게 낮습니다. Coma 보정 곡면은 다음 단계(P4)입니다.
- 시나리오의 위치·깊이·두께는 Synthetic 또는 공개 문헌 값입니다.

## 확인
