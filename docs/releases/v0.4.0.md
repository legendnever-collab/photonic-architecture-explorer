# Photonic Architecture Explorer v0.4.0 (P0~P4b)

Windows x64 오프라인 패키지입니다. 설치할 것은 없습니다.
1. ZIP을 풉니다.
2. `Start-Photonic-Architecture-Explorer.cmd`를 실행합니다.
3. Chrome 또는 Edge에 화면이 열립니다(127.0.0.1, 인터넷 불필요).

## v0.3.0 이후 새로 된 것

### P4 Coma 보정 곡면
- 반사면에 3·4차 Sag를 더해 비근축 η를 회복합니다.
- 결과: S1 0.32~0.58 → 0.9999~1.000, S4 0.47~0.54 → 0.995~0.999.
- 화면에서 보정 곡면 η, 보정량(PV/RMS/기울기), 보정 후 정렬 손실을 봅니다.

### P4 Micro-lens + 두 반사면 Family
- 발산각 Guard를 넘는 Port(SiPh SSC, Laser) 앞에 두 면 비구면(Aplanatic) Lens를 둡니다.
- Lens 재료는 Port 발산각에 따라 정합니다: 0.39 rad 이하는 Fused silica, 넘으면 Silicon.
- S3: Computed, 비근축 η 0.986~0.998.
- S5: Computed, Silicon Lens + 두 반사면 + Silica Lens, 비근축 η 0.987~0.988.
- 3D·2D·Fold 도면에 Lens를 그립니다.
- Lens 정렬 연구: ±1 µm 편심 손실과 1 dB 허용치. S3 0.7 µm, S5 0.38 µm.

### P4 Family 비교·자동 선택
- 왼쪽 카드의 "Lens Family" 선택으로 Lens Family를 다르게 돌립니다: 자동 / 항상 비교 / 사용 안 함.
- 결과에 Family 비교표가 나옵니다(η, 정렬 공차, 소자 수).
- 선택 규칙: 최고 η인 Family. 최고와 0.01 이내면 소자가 적은 Family.

### P4b 동시 오차와 Active alignment
- 모든 소자의 위치·기울기 오차를 동시에 주고, Passive 조립과 Active alignment 손실 분포를 계산합니다.
- Active alignment에는 정렬 후 고정 시 이동(±0.2 µm, 가정)이 포함됩니다.
- 결과: S1 Passive 1 dB 이내 6 % → M1 위치를 Active 정렬하면 0.01 dB.
- 공차 값은 왼쪽 "정렬 공차"에서 바꿉니다(가정값).

### P4b Glass 배치 What-if
- Glass 문제가 Fail이면 "What-if 계산" 버튼이 나옵니다.
- 가정 배치(Glass 두께, 도파로 매립 깊이, Fiber 높이)를 하나씩 바꿔 후보가 나오는 값을 찾습니다. 약 40 s 걸립니다.
- 결과: S2b-1550-glass는 매립 깊이 0.3 mm가 필요하고, 두께나 Fiber 높이를 바꿔서는 풀리지 않습니다.

## 알아둘 점
- η와 비근축 η는 Scalar Mode Overlap입니다. Total Coupling, Fresnel·코팅 손실, Package, 특허성은 계산하지 않습니다.
  - Silicon Lens는 코팅이 없으면 두 면 투과가 약 0.48입니다(AR 코팅 전제).
- 정렬 공차 모델은 Beam의 위치·각도 어긋남만 봅니다. 크기·초점 변화는 포함하지 않습니다. 비근축 계산과 15 % 이내로 확인했습니다.
- 계산 시간
  - Lens Family가 도는 S3·S5 Design: 20~50 s
  - "항상 비교" 모드: 수십 초 더 걸림
- 시나리오의 위치·깊이·두께는 Synthetic 또는 공개 문헌 값입니다.
