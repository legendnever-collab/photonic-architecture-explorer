계산 과정과 검증 근거

두 Port를 고정했을 때 어떤 후보가 만들어지고, 각 결과로 어디까지 판단할 수 있는지 살펴봅니다.

계산 흐름

단계를 열면 Input과 Output, 적용 조건, 오차 요인을 확인할 수 있습니다. Workspace는 Fast Evaluation으로 후보를 비교합니다. Wave 및 FDTD 단계는 선택한 Reference에서 별도로 실행했습니다.

  1. Two Fixed Ports 현재 Runtime

    두 Reference Plane의 위치, 도착·출발 방향, λ₀, 외부 매질 n, 두 축의 Mode를 읽습니다. 축과 Phase를 포함한 ordinary q가 Output입니다. Guided MFD만 주어지면 외부장의 Phase와 기준면은 미확정입니다.

    1/q = 1/R − iλ₀/(πnw²)

  2. Architecture Generator 현재 Runtime · Two Reflectors

    두 Port의 축 위에서 M1·M2 Vertex를 정하고 세 구간 길이와 반사 법선을 구합니다. Specular Reflection을 만족하는 Quadratic Curvature 후보를 생성합니다. 유한한 배치 집합에서 후보가 사라질 수 있습니다. Lens·High-order Surface 자동 합성은 장기 목표입니다.

    d′ = d − 2(d·n̂)n̂

  3. Geometry & Domain Screening 현재 Runtime

    후보마다 Chief Ray가 올바른 면을 순서대로 지나 Target 위치·방향에 도달하는지 검사합니다. Coplanar 정렬, Divergence, Aperture Tail 및 투영 Footprint를 점검해 통과·탈락 사유를 반환합니다. Guard 여유로 실제 수차나 조립 오차의 상한을 정할 수는 없습니다.

    θ ≤ 0.1 rad · max(3wproj|κ|) ≤ 0.15

  4. Gaussian / Ray / Fast Evaluation 현재 Runtime

    통과한 처방의 Source q를 각 반사면과 Target Plane까지 전달해 Beam Radius, Wavefront Curvature와 Mode Match를 구합니다. 두 축이 분리되는 Scalar Paraxial 근사에서 유효합니다. Clipping·Edge Diffraction은 추가 검증이 필요합니다.

    q₂ = (Aq₁+B)/(Cq₁+D)

  5. Vector Wave Propagation 고정 Reference · Partial

    복소 E/H와 경계 조건을 입력해 다음 면의 접선장과 Flux를 구합니다. 균질 공기 및 무한 PEC 접평면은 R16의 독립 대조가 있습니다. 명목 유한 곡면에서는 Source 절단, Edge Current와 수신 Projection 오차가 남습니다.

    Js = n̂ × H, Ms = −n̂ × E (등가면의 외향 법선)

  6. Selective FDTD / Meep Validation 오프라인 대조 · 자동 실행은 계획

    R19·R20은 평면파, 직선 SMF 및 고정 Facet에 한정된 독립 계산입니다. Yee Grid에서 성분별 위치와 시간을 맞춘 E/H, Flux Monitor와 격자 정련을 비교합니다. 직선 SMF의 기준 초과로 후속 Facet 재계산을 보류했습니다.

    ∂B/∂t = −∇×E

  7. Mode Overlap · Power · Loss Scalar는 현재 Runtime · 전체 Power는 Uncomputed

    같은 평면의 Scalar Mode 두 개로 정규화 Overlap을 평가합니다. Power에는 공통 정규화의 E/H, 면 방향과 적분 범위가 필요합니다. 실제 Insertion Loss에는 계면·코팅·회절과 수신 Guided Power가 필요합니다.

    ηmode = |⟨u₂,u₁⟩|²/(‖u₁‖²‖u₂‖²)

  8. Confidence-Tagged Candidate Comparison 현재 Runtime

    통과 후보의 Overlap, Path Length, Beam Footprint 및 Guard 여유를 읽고 추천·대안의 Trade-off를 표시합니다. 후보마다 Input SHA와 Evaluation이 연결됩니다. 순위는 탐색한 후보 집합에 한정됩니다.

    ΔL = L대안 − L추천

수식과 물리적 의미

Beam의 폭과 위상은 함께 전파됩니다

q₂ = (Aq₁ + B)/(Cq₁ + D)

Show Equations · Gaussian / ABCD

시간항 exp(+iωt), 전진 Carrier exp(−ikz), k=2πn/λ₀를 씁니다. 1/q의 실수부는 1/R이고 허수부는 −λ₀/(πnw²)입니다. w는 Intensity가 중심의 1/e²가 되는 반경입니다.

자유 전파의 행렬은 (A,B,C,D)=(1,L,0,1)이므로 q′=q+L입니다. Curvature κ의 국소 반사면은 (1,0,−P,1)이므로 q′=q/(1−Pq)입니다. 입사각 θ에서 Pₜ=2κₜ/cosθ, Pₛ=2κₛ cosθ입니다. 각 축에 광로 순서대로 행렬을 합성합니다.

Mode Overlap은 Target Mode와의 형상·위상 정합을 나타냅니다

η = |∫ u₁u₂* dA|² / [(∫ |u₁|² dA)(∫ |u₂|² dA)]

Show Equations · Normalized Scalar Mode Overlap

동일 Reference Plane과 축 위에서 u₁은 도착장, u₂는 수용장입니다. 각각을 자신의 L² Norm으로 나누면 η는 두 단위장의 내적 절댓값 제곱이 됩니다. Cauchy–Schwarz 부등식으로 0 ≤ η ≤ 1입니다. 도착장 진폭을 절반으로 줄이면 Power는 ¼로 줄고 이 η는 같습니다. −10 log₁₀η는 Mode Mismatch만 나타냅니다.

Power는 기준면을 통과하는 Energy Flux를 적분합니다

P = ½ Re ∫A (E × H*) · n̂ dA

Show Equations · Time-Averaged Poynting Flux

실수장의 E(t)×H(t)를 한 주기 평균하면 Peak Phasor의 교차항에 ½가 남습니다. n̂은 양의 Power 방향이며 역방향 성분은 부호가 바뀝니다. SI의 E[V/m], H[A/m], dA[m²]를 쓰면 P[W]입니다. Z₀H 및 임의 Source 진폭을 쓰는 Reference에는 그 정규화를 별도로 적용합니다. Pguided/Plaunch를 구하려면 두 Power가 같은 물리 스케일로 연결되어야 합니다.

Yee Grid에서는 같은 위치와 시간의 E/H를 비교해야 합니다

∂D/∂t = ∇×H − J,   ∂B/∂t = −∇×E

Show Equations · FDTD / Yee Grid

선형 무분산 매질에서 D=εE, B=μH입니다. 각 Curl을 중심 차분해 서로 다른 공간 위치의 성분을 반 시간 간격씩 번갈아 갱신합니다. 직교 균일 격자의 표준 명시적 갱신은 vmax Δt √(Δx⁻²+Δy⁻²+Δz⁻²) ≤ 1의 CFL 조건을 갖습니다. 안정한 시간 간격에서도 수치 파수는 연속계와 다를 수 있습니다.

성분별 native 위치에서 관측면으로 보간하고 동일 Phasor Convention으로 맞춥니다. R20의 Meep DFT는 H의 반 스텝을 이미 반영하므로 추가 Phase 회전은 중복됩니다. Mesh 정련, Source/Mode Excitation 변경, 면별 Power Balance와 해석 HE11 Profile 대조를 별도로 봅니다. Flux 폐합만으로 국소 Field 정확도를 판정할 수 없습니다.

B · PIC SSC ↔ Glass Waveguide, 1310 nm

M4B-LIT-001은 문헌의 Guided Width를 사용한 Gaussian Proxy입니다. 실제 SSC의 외부 Complex E/H는 Evidence Insufficient입니다.

1 · Fixed Ports

Source (0,0,0) mm와 Target (2,0,2) mm의 각 기준면에서 +X, t=−Z, s=+Y를 가정했습니다. 공기 중 MFD 2.73/3.79 µm와 Flat Phase를 두 면에 가정했습니다. 원문 Width는 Glass의 Guided Mode 값입니다. 실제 SSC의 방출장, Phase, Polarization 및 외부 Reference Plane 측정이 필요합니다.

2 · Architecture Generation

이 대조는 기존 처방을 고정해 검사했습니다. M1 (1,0,0) mm와 M2 (1,0,2) mm에서 반사하며, 양쪽 κₜ/κₛ는 353.55/707.11 m⁻¹입니다. 표시된 Package와 Body도 개념 가정입니다.

3 · Fast Optical Evaluation

Geometry Closure는 Pass입니다. 두 축의 Gaussian Divergence 0.3055/0.2200 rad가 0.1 rad를 넘어 Model Domain은 Fail입니다. 이후 Beam Envelope, Footprint 및 Overlap 수치는 보류합니다.

4 · Wave-Level Evaluation

같은 SSC의 기준면에 귀속되는 복소 E/H와 Flux 정규화가 필요합니다. 이 처방의 Diffraction, Vector Propagation 및 Poynting Flux는 Uncomputed입니다.

5 · Engineering Decision

선언한 Envelope Geometry는 통과했습니다. 실제 Package Feasibility, Mode Overlap 및 Total Coupling은 Uncomputed입니다. 이 근거로 추천하거나 대안의 우열을 정할 수 없습니다.
